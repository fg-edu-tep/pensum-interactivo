# Review with Mauricio Guerrero (2026-10-29) — what was built

Source: "Pensum IELE — Improvements from Review with Mauricio Guerrero" (agreed items + proposals).
Branch `claude/loving-edison-ftxjls` (restarted from `main` after PR #3 merged).

Decisions taken while building (confirmed with the product owner):
- **CLE and CI slots** are enabled *by requirement* like the other electives (CLE has no closed catalog → always open; CI opens when an integrador elective is takeable).
- The admin **credit-threshold table stays**, empty by default (the old defaults are retired once per catalog, flag `creditUnlocksRetired`).
- The outage guide links to Registro's "¿Cómo hacer mi horario?" for now (`web/lib/links.ts`, override with `NEXT_PUBLIC_FALLBACK_GUIDE_URL`).

---

## 1. Future planning + checkout step 0

- One evaluator, `web/lib/planning.ts` (A = approved, C = cart):
  - **now** — hard prerequisites in A; correquisites and "*" (may be taken together) in A ∪ C; credit restrictions against credits(A).
  - **next** — everything in A ∪ C (credits(A ∪ C)).
- The map's market grows live: putting Variable compleja in the cart makes Elementos de sistemas eléctricos and Teoría electromagnética available (correquisite), with no need to confirm.
- **Step 0 of checkout** ("Revisar mi canasta"): "Puedes agregarlas este mismo semestre" (enabled by a correquisite in the cart, with an *Agregar* button) and "Podrás verlas el próximo semestre" (each with "se habilita con …").
- After step 0 the map marks next-semester courses with a **blue outline + "La vas a poder ver"** — a marker, never a fill. Markers are cleared as soon as the cart changes.
- Buying without requirements is allowed; the side panel shows **"Ojo: no has aprobado X"**.

## 2. Slots by requirement

- `web/lib/electiveAvailability.ts` is shared by the map and the elective picker, so they can't disagree.
- **EFI** and **CLE** are always enabled ("Verifica sus prerrequisitos").
- **Electiva / CI** are enabled when ≥ 1 course of the slot's catalog can be taken now. A catalog with no evaluable data stays enabled.
- Electives whose prerequisites name real courses outside the pensum must have them approved. Exam/equivalence tokens and English-language codes are informational. Electives with no data read **"Verifica prerrequisitos"**, never "Puedes tomarla".
- Graduate-only electives (Registro *Restricción de nivel* includes only Magíster/Doctorado/Especialización) are blocked for pregrado plans.
- The credit-threshold defaults are retired (the table is kept for admins, empty).

## 3. Half-box elective subdivision

- `web/lib/electiveBoxes.ts`: each elective box = two 1-credit halves. A course of k credits fills k halves forward from where it's placed; the following box shows "Nombre (cont.)" and "Libre · 1 cr" for the free half.
- Tooltip: "Esta materia vale 4 créditos y ocupa 2 casillas". Boxes always read "2 cr". No reflow. Credits beyond the last box show "+N cr por encima".
- Old assignments are migrated on load (`migrateAssignments`).

## 4. Data: restrictions, latest term, offering dates

- **4a** Registro "Excluye semestres 1–n" → `minCredits = 15 × n` (`web/lib/import/restrictionCredits.ts`), logged by the seed. The requirement tree shows "60 créditos aprobados (equivale a 4 semestres)".
- **4b** The latest term of each course wins. The seed prints a **coverage report** of pensum/elective codes missing from Registro since `REGISTRO_WINDOW_FROM` (default `202310`). Current gaps: IELE2150, IELE3118, IELE3218, IELE3502, MATE1201.
- **4c** `lastOfferedTerm` (from Registro) and `nextOfferingTerm` (the department's planning, editable in the admin course row and elective table; `YYYYPP`) are shown in the tooltip, side panel and picker.

## 5. Copy and fixes

- **5a** "Qué desbloquea" → **"Qué se me habilita"** ("¿Qué podré ver si apruebo o inscribo este curso?"), split into "Este mismo semestre (por correquisito)" and "El próximo semestre".
- **5b** CBU legend: "1 CBU Colombia · 2 CBU de áreas diferentes · 2 CBU libres".
- **5c** Quick select by semester: each selection **replaces** the previous one ("Aplicar: …"); the panel says how many courses are newly marked.
- **5d** API preflight (`/api/oferta/health`, 5 s probe, cached 5 min up / 30 s down). When the API fails, planning (cart, schedules, "qué se me habilita") is disabled with a banner and a link to the guide. Marking approved courses still works. Re-checked periodically. `OFERTA_PREFLIGHT=off` skips it in local dev without network.

## 6. Electives Venn (`/embed/electivas`)

- Two sets only (Eléctrica / Electrónica). The master's set was dropped.
- Filters: **Curso integrador** and **Se dicta este semestre** (the API one is disabled while the API is down).
- Clicking an elective opens an inline detail (`/api/electives/detail`): prereqs/coreqs by name, credits, offered this term, credit restriction, last/next offering, and **"Planear con esta materia"** links to the standard plan.

## 7. Portal layout proposal

- `/portal` — a proposal page (Planea tu semestre · Electivas por programa · Guía del pensum) for discussion; not linked from the app yet.
